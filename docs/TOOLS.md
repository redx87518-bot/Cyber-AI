# Cybersecurity Tools

## Available Tools

### SOC
- `getAlerts` - Retrieve alerts from database
- `getInvestigations` - Get investigations
- `getIncidents` - Get incidents

### Threat Intelligence
- `enrichIOC` - Enrich indicators of compromise
- `checkAbuseIPDB` - Check IP reputation
- `searchThreatFox` - Search ThreatFox
- `queryMalwareBazaar` - Query malware hashes
- `getOtxIntel` - OTX threat intelligence
- `scanUrl` - URLScan.io lookup
- `dnsLookup` - DNS resolution
- `rdapLookup` - RDAP registration data
- `whoisLookup` - WHOIS registration data

### GRC
- `getRisks` - Get GRC risks
- `createRisk` - Create new risk
- `getControls` - Get controls
- `iso27001Lookup` - ISO 27001 control lookup

### Vulnerability
- `getNvdCve` - NVD CVE lookup
- `mitreLookup` - MITRE ATT&CK technique lookup

### Reporting
- `generateReport` - Generate text report
- `saveReport` - Save report to database

### Utilities
- `getSettings` - Get current settings
